Domain notes

ECG-gated contrast-enhanced CT. Blood pool ~200–600 HU vs NCCT ~40–60 HU (MedDINOv3 pretraining domain). Viewer clip recommended: --clip -1000 1000 for CECT. nnUNet training uses HU-normalised inputs.

Inflation Strategies

All strategies inflate patch_embed.proj.weight from (768, 3, 16, 16) → (768, 3, d_patch, 16, 16). All other ViT weights are copied unchanged.

StrategyScriptCheckpoint nameTrainer classChannel treatmentDepth normalisation
average inflate_weights_3d.py --inflation average meddinov3_inflated_average_d2.pth meddinov3_3d_primus_multiscale_Trainer Each channel preserved independently ÷ d_patch
centering default inflate_weights_3d.py --inflation centering meddinov3_inflated_center_d2.pth meddinov3_3d_primus_multiscale_Trainer Each channel preserved; center slice = full weight, rest zero none (sparse)
Ashwin_3d_inflation inflate_weights_3d_ashwin.py meddinov3_inflated_ashwin_d2.pth meddinov3_3d_ashwin_primus_multiscale_Trainer 3 channels summed → redistributed equally (channel-average init) none (d_patch copies of equal weight)

3D training interventions (all 3D trainers)

sinusoidal depth_pos_embedOrdered depth encoding from step 0 (zero-init left model depth-blind: identical positional code at every depth slice)
OptimizerAdamW betas=(0.9,0.98); 10-epoch linear warmup then poly decay. (Prior: SGD — caused plateau at 0.15 Dice.)
grad_clip_norm1.0 on 3D trainers (was 12, the SGD-era default — effectively no clipping for AdamW). Set via self.grad_clip_norm.
Differential LRsdecoder ×1.0 · patch_embed_3d ×0.5 (wd=0) · depth_pos_embed ×0.5 (wd=0) · backbone ×BACKBONE_LR_SCALE (default 0.1, was 0.3)
patch_embed_3d wd=0Prevents the inflated pretrained kernel from decaying; for centering init this also keeps the non-centre slices near zero
Per-group PolyLREach param group decays from its own initial_lr, not a shared value
d_patch choiced=16 = 600 tok (3.1× pretrained) — safe baseline. d=8 = 1200 tok (6.1×) — push only after d=16 converges.

Feature Viewers

2D Viewer feature_viewer_2d.py

Per-slice 2D ViT features, PCA/similarity colourmap.

python feature_viewer_2d.py \
--nifti scan.nii.gz \
--checkpoint meddinov3_2d.pth \
--clip -1000 1000

Accepts 2D or any inflated 3D checkpoint (auto-deflates by averaging depth dim).

3D Viewer feature_viewer_3d.py

Axial/coronal/sagittal crosshair + similarity probe. Scroll, slider, keyboard (↑↓ PgUp/Dn) navigate axial slices.

python feature_viewer_3d.py \
--nifti scan.nii.gz \
--checkpoint meddinov3_2d.pth \
--clip -1000 1000

Same checkpoint flags for all inflation variants — auto-deflation handles 5D patch_embed weights identically.
