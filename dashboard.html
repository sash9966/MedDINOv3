3D training interventions (all 3D trainers)

sinusoidal depth_pos_embedOrdered depth encoding from step 0 (zero-init left model depth-blind: identical positional code at every depth slice)
OptimizerAdamW betas=(0.9,0.98); 10-epoch linear warmup then poly decay. (Prior: SGD — caused plateau at 0.15 Dice.)
grad_clip_norm1.0 on 3D trainers (was 12, the SGD-era default — effectively no clipping for AdamW). Set via self.grad_clip_norm.
Differential LRsdecoder ×1.0 · patch_embed_3d ×0.5 (wd=0) · depth_pos_embed ×0.5 (wd=0) · backbone ×BACKBONE_LR_SCALE (default 0.1, was 0.3)
patch_embed_3d wd=0Prevents the inflated pretrained kernel from decaying; for centering init this also keeps the non-centre slices near zero
Per-group PolyLREach param group decays from its own initial_lr, not a shared value
d_patch choiced=16 = 600 tok (3.1× pretrained) — safe baseline. d=8 = 1200 tok (6.1×) — stable. d=4 = 2400 tok (12.2×) — finest depth; ~4× d=8 attention memory, start bs=1.
MEDDINOV3_BATCH_SIZEEnv override (single-GPU) applied after _set_batch_size_and_oversample. Flip 1↔2 without code changes; d=4 scripts default to 1.
Per-epoch [GPU] logon_epoch_end logs peak_alloc / peak_reserved / free / total (batch_size) to the training log, then resets peak. nvidia-smi snapshot at job start in the .out. Applies to all 3D trainers (d4/d8/d16/FiLM).

Identical d=4 token budget (2400 tok, 12.2×), identical training setup, bs=1. The only variable is the patch_embed inflation strategy. Judge on the topology suite (Ao/PA clDice, false-disconnected, switch-flag, Myo fragmentation), not just Dice.

CHD MedDINO 3D Inflation Ablation Plan

Congenital heart disease segmentation is not only a voxel-labeling problem; the disease diagnosis constrains the topology of the heart and great vessels. A 3D-inflated MedDINO model may benefit from pretrained CT features and global anatomical context, while diagnosis-aware conditioning and topology-aware losses may help recover small, abnormal, or ambiguous vascular structures that standard Dice/CE training underweights.

1 · Current Approach

  • MedDINOv3 / DINO-style ViT backbone adapted to medical CT.
  • 2D pretrained weights inflated into 3D — keeps useful in-plane pretrained representations while gaining through-plane anatomical context.
  • 1×1×1 learnable contrast adapter adapts the input distribution toward contrast-enhanced CT without immediately destroying the pretrained backbone.
  • 3D context is expected to help congenital anatomy where topology, vessel continuity, chamber adjacency, and abnormal great-vessel relationships matter.
  • Current whole-heart Dice ≈ 0.89 on ~100 cases; nnU-Net remains slightly ahead overall.
  • Weak structures: pulmonary arteries & great arteries — small, elongated, topology/continuity-sensitive.

2 · Why the Current Components Might Work

A · 2D→3D weight inflation

Preserves pretrained in-plane filters/tokens, adds z-axis context, avoids random 3D init. Hypothesis: helps especially in low-data settings.

B · 1×1×1 input/contrast adapter

The 1×1×1 input adapter is a lightweight learnable bridge between contrast-enhanced CT intensities and the pretrained MedDINO representation. It lets the model adapt low-level contrast statistics before the inflated encoder, without forcing the entire pretrained backbone to relearn the input distribution from only ~100 cases.

C · Depth variants d16 / d8 / d4

The d16/d8/d4 variants test how much through-plane context is useful. Larger depth gives more 3D anatomical context, but smaller depth can reduce memory, over-smoothing, and overfitting. The best setting may differ for whole-heart Dice versus pulmonary artery and great-vessel continuity.

D · Diagnosis conditioning / disease topology

In CHD the diagnosis constrains expected topology (chamber sizes, outflow-tract relationships, vessel positions, missing/abnormal connections). Oracle conditioning shows an upper bound; predicted-diagnosis conditioning is the deployable form.

E · FiLM conditioning

FiLM conditioning is a plausible mechanism for injecting diagnosis information, but it is not guaranteed to help. If the diagnosis signal is weak, injected too late, or dominated by the segmentation loss, the network may ignore it. The ablation suite therefore tests diagnosis as multi-task supervision, bottleneck FiLM, decoder FiLM, and multiscale FiLM separately.

F · Small-vessel topology losses

Pulmonary arteries and great arteries are small, elongated, and clinically topology-sensitive. Standard Dice can reward volume overlap even when vessels are fragmented. Vessel-aware sampling, class-balanced losses, clDice/centerline metrics, and class-specific post-processing are included to test whether we can improve continuity without sacrificing whole-heart performance.

G · Post-processing

Connected-component filtering, small-island removal, hole filling, vessel-specific repair — evaluated per class so it cannot inflate whole-heart Dice while harming vessels.
